# 5. Dúvidas comuns

**Digitei uma quantidade errada. Como corrijo?**
Enquanto a contagem está aberta, basta apagar e digitar de novo. Depois de finalizada, ela não muda mais; a correção
entra como uma nova contagem ou uma movimentação.

**Apaguei o número sem querer. O produto ficou zerado?**
Não. Campo vazio é "não contado". Zero só quando você digita 0.

**Fiquei sem internet no meio da contagem. Perdi o que fiz?**
Não. As quantidades ficam guardadas no celular e são enviadas quando o sinal volta.

**Não vejo a aba Cotações.**
Ela aparece só para quem tem o papel de comprador, aprovador ou administrador.

**Não vejo a minha unidade.**
Peça ao administrador para liberar a unidade para você.
